# 面向 ECG 模板匹配的随机计算 FPGA 工程

本项目以 32 维 ECG 心拍模板匹配为数字信号处理载体，研究随机计算中随机源共享带来的精度、相关性、资源、时序与能耗权衡。工程已完成 MATLAB 数据链、随机源架构扫描、100 拍 RTL 回归、Artix-7 布局布线以及最终综合分析。

## 最终状态

- MATLAB R2024b 从公开 MIT-BIH 119 与 NSTDB 119e12 重新生成 Day 1–4 数据和指标。
- 32 维 Q8 基线在 416 个 12 dB 配对测试拍上达到 97.36% Accuracy、93.71% V 类 F1。
- 1023 周期、96 路独立 LFSR 在 100 拍硬件集上 100% 复现 Q8 判决。
- 简单共享 XOR 和循环移位均系统性退化为全 N，作为失败对照保留。
- 最佳低成本共享方案使用 4 路 LFSR：100 拍完全复现 Q8；416 拍与 Q8 一致率 99.76%，仅 1 拍分歧。
- 含噪训练拍校准的自适应停机保持上述判决，416 拍平均有效周期为 234.38；含装载、流水和检查停顿的平均总延迟为 2.69 us。
- 10 个代表架构均在 Artix-7 `xc7a35tcsg324-1`、100 MHz 下完成布局布线并满足时序。

本公开仓库仅保留核心源代码；原始数据、实验结果、综合报告和研究笔记未上传。

## 最重要的工程结论

随机源数量不是精度的单调决定因素。96 路多种子 LFSR 仍会因序列相位关系产生 15 个完整测试集分歧；盲目选择 96 个“低相似”置换甚至会彻底失败。根据实际点积拓扑进行配对、让 N/V 模板侧误差共同变化，并按判决敏感度分组，才能把随机源从 96 路降到 4 路，同时只保留 1 个 Q8 分歧。

本任务中，传统 Q8 双 MAC 基线仍是面积、速度和单拍能量最优方案：130 LUT、266 FF、2 DSP、0.64 us。随机计算方案的价值不是声称全面取代定点 MAC，而是展示在不用 DSP、需要大规模并行或允许近似时，如何系统地控制相关性和共享开销。

## 固定实验条件

- 数据：MIT-BIH 119、NSTDB 119e12，360 Hz。
- 心拍：R 峰前 90 点、R 峰及之后 162 点，共 252 点。
- 特征：32 维有符号 Q8，范围 `[-127,127]`。
- SC：双极性编码、XNOR 乘法、10 位 LFSR、1023 周期。
- FPGA：Artix-7 `xc7a35tcsg324-1`，100 MHz。
- 顶层接口：8 位特征串行装载，片内保存 32 维向量，避免 303 个并行 I/O 超出封装。

## 公开代码结构

- `fpga/rtl`：参数化随机计算分类器与8位串行装载顶层。
- `fpga/tb`：SystemVerilog功能验证平台。
- `fpga/constraints`：Artix-7、100 MHz约束。
- `matlab/functions`：随机源生成、架构评估、指标计算和自适应停止函数。
- `matlab/tests`：LFSR周期、阈值映射和随机源核心测试。
- `config`：冻结的算法和器件参数。

由于公开版不包含ECG原始数据、冻结接口向量、生成脚本及Vivado结果，克隆后不能直接复现论文式全流程。该仓库主要用于展示核心RTL与MATLAB算法实现。

## 结论边界

本工程不是端到端医疗诊断系统。R 峰、标签、预处理和特征提取均来自 MATLAB 离线流程，数据只来自记录 119；不能声称具有跨患者临床泛化能力。Vivado 功耗为向量无关估计，不等同于开发板实测功耗。
